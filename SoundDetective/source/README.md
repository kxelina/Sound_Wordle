# Local music assets / 本機音樂素材

The M01 song recording and its extracted evidence WAV are not included in this source repository.
They are kept locally and excluded from Git. The synthesized T01–T08 and W01–W06 challenges and free composition do not require them.

The existing M01 configuration names `source/1.打上花火.mp3` and
`content/music_cases/assets/M01-evidence.wav`, with checksum verification.
Provide your own permitted local assets matching that configuration if you need to run the existing M01 case.

M01 原曲及證物 WAV 不包含於此原始碼倉庫，且已從 Git 排除。
音色案件、六個 Sound Wordle 案件及自由創作不依賴這些錄音。
歌曲案件的本機音源路徑與校驗資訊位於 `../content/music_cases/M01.json`。
